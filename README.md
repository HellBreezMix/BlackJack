# BlackJack Casino (OpenComputers)

Чистая версия казино-блэкджека под ваше железо.

## Файлы

- `config.lua` — все настройки (админы, стороны, цены скупки, ставки, цвета)
- `main.lua` — вся логика + интерфейс

## Установка

1. Создайте папку `/BlackJack` на компьютере
2. Скопируйте туда оба файла
3. Запуск:

```lua
lua /BlackJack/main.lua
```

Или добавьте в `.sh` / автозапуск.

## Железо (как на скриншоте)

- **Левый сундук** стоит **сверху** транспозера → приём предметов для пополнения счёта
- **Правый сундук** стоит **сверху** ME Interface (с Database 3) → запас предметов / будущие выплаты

В `config.lua`:

```lua
config.hardware = {
    transposerSide = 1,   -- top
    meSide = 1            -- top
}
```

## Как играть

1. Игрок касается экрана → авторизация по нику
2. Видит свой баланс ЭМ (сохраняется между рестартами)
3. Может **Пополнить счёт** — кладёт предметы в левый сундук и жмёт кнопку (скупка по ценам из конфига)
4. Выбирает ставку стрелками (мин/макс настраиваются в админке)
5. **ИГРАТЬ** → Hit / Stand
6. Blackjack платит **3:2** (2.5x)

## Админ-панель

Видна только игрокам из списка `config.admins` (по умолчанию `hellbreez` и `Lofland`).

Вкладки:
- **Ставки** — минимальная и максимальная ставка
- **Скупка** — список предметов + кнопка «Добавить предмет»

### Добавление предмета для скупки
1. Жмёшь «+ ДОБАВИТЬ ПРЕДМЕТ»
2. Кладёшь предмет в левый сундук (транспозер сверху)
3. Жмёшь ОК → программа считывает предмет
4. Редактируешь отображаемое имя и цену (можно 0.1, 1, 10…)
5. Сохраняешь

## Валюта

Основная валюта — **ЭМ** (виртуальный баланс).

Начальные цены можно задать в `config.buyPrices`, дальше всё управляется из админки.

## Топ игроков

Топ 15 считается по **сумме наигранных ЭМ** (все сделанные ставки).  
Пример: поставил 300 ЭМ → в топ добавляется +300 (независимо от победы/поражения).

## Карты

Пиксельная отрисовка всех 52 карт (раскладка мастей + фигурные J/Q/K) в стиле оригинального кода.
